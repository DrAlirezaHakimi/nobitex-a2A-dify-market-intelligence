# راهنمای فارسی — سامانه هوشمند تحلیل بازار Nobitex مبتنی بر A2A و Dify

این پروژه یک نمونه پژوهشی و **صرفاً تحلیلی و فقط‌خواندنی** است. در حالت `demo` از داده‌های ساختگیِ برچسب‌خورده استفاده می‌کند و در حالت `live` فقط داده‌های عمومی بازار نوبیتکس را می‌خواند. اتصال به حساب خصوصی، کیف پول و ثبت سفارش واقعی در این نسخه وجود ندارد.

## شروع سریع در ویندوز

1. Python نسخه 3.12 یا بالاتر را نصب کنید.
2. فایل پروژه را در یک پوشه محلی استخراج کنید.
3. فایل `start_windows.bat` را اجرا کنید.
4. پس از راه‌اندازی، داشبورد را در نشانی http://127.0.0.1:8001 باز کنید.
5. برای استفاده از داده عمومی بازار، فایل `.env` ایجادشده را باز کنید و مقدار `MARKET_MODE=live` را تنظیم کنید؛ سپس برنامه را مجدداً اجرا کنید.

## اجزای معماری

- دریافت و کنترل کیفیت داده‌های عمومی بازار
- پنج عامل منطقی: جریان سفارش، روند، نقدشوندگی، ریسک و تصمیم
- هماهنگ‌ساز پایتونی و API مبتنی بر FastAPI در پورت 8000
- داشبورد محلی در پورت 8001
- دو الگوی قابل ورود به Dify: گردش‌کار پایه و توضیح‌گر اختیاری مبتنی بر LLM

عامل‌ها در این نسخه در یک فرایند پایتون اجرا می‌شوند و سرویس‌های مستقل جداگانه نیستند. پیاده‌سازی A2A یک زیرمجموعه محدود JSON-RPC است و ادعای انطباق کامل با آخرین SDK یا مشخصات A2A ندارد.

## اتصال به Dify

1. فایل‌های YAML پوشه `dify/` را در Dify Studio وارد کنید.
2. نشانی HTTPS قابل دسترس برای API پورت 8000 را در متغیر ورودی ورک‌فلو تنظیم کنید.
3. در صورت استفاده از Dify Cloud، سرویس API باید از طریق HTTPS در دسترس باشد.
4. در Environment Variables دیفای، متغیر محرمانه `A2A_API_KEY` را بسازید و مقدار آن را برابر `API_KEY` محلی قرار دهید؛ Workflow این مقدار را در هدر `X-API-Key` می‌فرستد.
5. کلید برنامه Dify که از Access Point ساخته‌اید، کلید جداگانه‌ای است؛ آن را در `.env` محلی با نام `DIFY_API_KEY` قرار دهید تا داشبورد بتواند Workflow را اجرا کند.
6. کلیدها، توکن ngrok و فایل `.env` را در GitHub بارگذاری نکنید.

## اجرای لینوکس

```bash
chmod +x start_linux.sh run_linux.sh
./start_linux.sh
```

## اجرای Docker

فایل محلی `.env` را بر اساس `.env.example` بسازید، یک `API_KEY` قوی قرار دهید و اجرا کنید:

```bash
docker compose up --build -d
```
