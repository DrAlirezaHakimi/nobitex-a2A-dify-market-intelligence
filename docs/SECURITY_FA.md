# راهنمای امنیتی و مدیریت کلیدها

## دو کلید متفاوت را با هم اشتباه نگیرید

این پروژه دو راز مستقل دارد:

### ۱. کلید سرویس A2A — `API_KEY`

- در فایل محلی `.env` کنار برنامه قرار می‌گیرد.
- هنگام ساخت اولین فایل تنظیمات، برنامه یک مقدار تصادفی قوی ایجاد می‌کند.
- درخواست‌های محافظت‌شده به API باید آن را در هدر `X-API-Key` بفرستند.
- اگر Dify Workflow قرار است API را فراخوانی کند، همین مقدار را در Dify Studio به‌عنوان Environment Variable محرمانه با نام `A2A_API_KEY` تنظیم کنید. در HTTP Request node هدر `X-API-Key` را به `{{#env.A2A_API_KEY#}}` متصل کنید.

### ۲. کلید برنامه Dify — `DIFY_API_KEY`

- از بخش Access Point در Dify Studio برای برنامه Workflow ساخته می‌شود.
- در فایل محلی `.env` با نام `DIFY_API_KEY` قرار می‌گیرد.
- فقط زمانی لازم است که داشبورد محلی بخواهد Workflow منتشرشده را از طریق API سرویس Dify اجرا کند.
- این کلید جایگزین `API_KEY` سرویس A2A نیست.

**بنابراین ساختن کلید جدید Dify، کلید A2A را ایجاد یا جایگزین نمی‌کند.**

## پیکربندی امن Dify

در فایل‌های YAML این مخزن، `A2A_API_KEY` به‌صورت Secret Environment Variable تعریف شده است. پس از Import، مقدار آن را در Studio تنظیم کنید. مقدار واقعی کلید را در YAML عمومی قرار ندهید.

## ngrok و مرز شبکه

- فقط پورت `8000` (API) را در صورت نیاز به Dify Cloud از طریق HTTPS در دسترس قرار دهید.
- پورت `8001` (داشبورد) باید فقط روی loopback باقی بماند.
- URL عمومی را در `PUBLIC_BASE_URL` قرار دهید و آن را بدون اسلش انتهایی وارد کنید.
- دامنه ngrok باید هنگام اجرای Workflow فعال باشد.

## موارد ممنوع برای Commit

هرگز این موارد را در GitHub بارگذاری نکنید:

- فایل واقعی `.env`
- کلیدهای API، توکن ngrok یا رمز عبور
- کلید خصوصی یا اطلاعات حساب صرافی
- پایگاه داده SQLite و تاریخچه محلی
- داده خصوصی یا خروجی‌های حاوی اطلاعات هویتی

فایل `.env.example` فقط شامل placeholder است و برای شروع استفاده می‌شود.

## محدودیت امنیتی محصول

این مخزن یک نمونه پژوهشی است و جایگزین ارزیابی امنیتی پیش از استقرار عملیاتی نیست. قبل از هرگونه استقرار عمومی، TLS، محدودیت دسترسی، rate limit، ثبت رخداد، مدیریت رازها، به‌روزرسانی وابستگی‌ها و سیاست نگهداری داده باید جداگانه بررسی شوند. اجرای معامله واقعی در این نسخه وجود ندارد.
