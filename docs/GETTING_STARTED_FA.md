# سامانه هوشمند پایش بازار نوبیتکس با معماری A2A

**نسخه آزمایشی 0.1 – تهیه شده برای دکتر علیرضا حکیمی** | [alirezahakimi.ir](https://alirezahakimi.ir)

این بسته یک نمونه **قابل‌اجرا** برای اسکن همه نمادهای قابل‌دریافت از نوبیتکس، تحلیل موازی توسط ۵ عامل با زیرمجموعه‌ای از پروتکل A2A، رتبه‌بندی BUY / SELL / HOLD، داشبورد فارسی و اتصال با Dify است. **هیچ معامله واقعی انجام نمی‌دهد.**

## راه‌اندازی فوری در ویندوز

۱. ZIP را Extract کنید و Python 3.11+ نصب داشته باشید.
۲. روی `run_windows.bat` دوبار کلیک کنید؛ یک پنجره سرور باز می‌شود.
۳. در مرورگر آدرس `http://127.0.0.1:8000` را باز کنید. حالت پیش‌فرض **Demo / داده ساختگی** است.
۴. برای دیدن API به `http://127.0.0.1:8000/docs` بروید.

## راه‌اندازی با ترمینال

```bash
python -m pip install -r requirements.txt
python -m app
```

## تبدیل به داده عمومی واقعی

در ترمینال ویندوز (همان پنجره پیش از اجرا):

```bat
set MARKET_MODE=live
py -m app
```

در لینوکس:

```bash
MARKET_MODE=live python3 -m app
```

در حالت live تنها اردربوک عمومی و آمار بازار خوانده می‌شود؛ دسترسی به `apiv2.nobitex.ir` از شبکه شما باید برقرار باشد. **موفقیت اتصال از محیط فعلی تست نشده است.**

## دریافت گزارش

```bash
curl "http://127.0.0.1:8000/api/scan?top_k=12"
```

- `/api/scan` نتیجه اسکن همه بازارهای سالم، حذف‌ها، بالاترین سیگنال خرید/فروش و جزئیات عامل‌ها.
- `/api/paper/preview` فقط محاسبه اندازه فرضی سناریو (POST)، بدون سفارش.
- `/a2a/orderflow/.well-known/agent-card.json` معرفی عامل؛ همچنین trend, liquidity, risk, decision.
- `POST /a2a/{agent}` فراخوانی A2A با `message/send`، `tasks/get` (زیرمجموعه A2A 0.2.6).
- `/health` وضعیت سرویس.

## اتصال به Dify

۱. وارد بخش Studio شوید و Create App → Import DSL را انتخاب کنید.
۲. فایل `dify/Hakimi_Nobitex_A2A_Gateway.yaml` را وارد کنید.
۳. در نود `Start` نشانی `backend_url` را وارد کنید؛ مثال محلی `http://host.docker.internal:8000` فقط در **Dify self-hosted** داخل همان شبکه ممکن است. Dify Cloud به `localhost` دسترسی ندارد.
۴. برای Dify Cloud، backend را فقط از طریق HTTPS و احراز هویت قوی منتشر کنید. مقدار `X-API-Key` را در پیکربندی امن HTTP Request نود تنظیم کنید؛ کلید را در YAML منتشر نکنید.
۵. در HTTP Request آدرس و پارامترها را بررسی کنید. `Run` را بزنید. ممکن است بسته به نسخه Dify نیاز به ویرایش DSL باشد؛ **در Cloud هنوز تست عملی نشده است.**

**مهم:** گراف Dify یک «درگاه نمایش» است. تعامل واقعی عامل‌ها روی سرور FastAPI صورت می‌گیرد. اتصال به مدل زبانی داخل Dify برای توضیح خروجی اختیاری است؛ نتیجه عددی باید همچنان در کد قطعی بررسی شود.

## اجرا روی اینترنت

راه‌اندازی عمومی فقط با TLS، API_KEY قوی، reverse proxy، rate limit، فایروال، مدیریت کلید و کنترل log مجاز است. برای bind روی تمام اینترفیس‌ها `BIND_HOST=0.0.0.0` و `API_KEY` باید تنظیم شوند. صرف تنظیم کلید کافی نیست.
